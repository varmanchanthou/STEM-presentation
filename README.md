## 🚀 How to Host on GitHub Pages
1. Upload the files in this folder (`index.html`, `BIOCONVERT_MINI_Khmer_STEM_Presentation.html`, `.nojekyll`, and `README.md`) to your GitHub repository.
2. Go to **Settings** → **Pages** in your GitHub repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` (or `master`) branch and `/ (root)` folder, and click **Save**.
4. Your presentation will be live at `https://<your-username>.github.io/<repository-name>/`.

## 📦 Files Included
- `index.html` — Main entry point for GitHub Pages (self-contained 10-slide Khmer STEAM & 3D interactive presentation).
- `BIOCONVERT_MINI_Khmer_STEM_Presentation.html` — Named copy of the presentation for direct offline or local browser use.
- `.nojekyll` — Ensures GitHub Pages serves all static assets immediately without Jekyll processing.
